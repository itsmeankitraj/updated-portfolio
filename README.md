# Ankit Raj Portfolio

Responsive React + Vite personal portfolio with a private owner dashboard at `/admin`.

- Public website works with the bundled profile, resume and certificates.
- Supabase adds owner authentication, editing, uploads and live publishing.
- GitHub is the source-code repository; Netlify is the recommended host.

Read [SETUP.md](./SETUP.md) for the exact password setup, Supabase SQL, local development and deployment steps.
